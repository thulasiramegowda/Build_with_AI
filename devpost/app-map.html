CodePulse Architecture & System Tour

Interactive summary of the completed repository intelligence engine and full-stack architecture.

1. Repository Static Scanner

server/src/engine/staticAnalyzer.ts

  • Extracts Express routes: router.get, app.post.
  • Normalizes parameterized path tokens: /api/crops/:id → /api/crops/{param}.
  • Captures client Axios & Fetch calls with caller component names.

2. API Contract Intelligence

server/src/engine/contractMatcher.ts

  • Performs cross-tier comparison between client requests and route implementations.
  • Flags path discrepancies, HTTP method mismatches, and omitted query/body parameters.
  • Generates line-numbered citations and confidence scores.

3. Change Impact & Mermaid Graph

server/src/engine/impactBuilder.ts

  • Parses PR unified diff hunks (diffParser.ts).
  • Constructs dynamic Mermaid graph TD diagrams linking changed files to routes, client components, and missing tests.
  • Provides interactive node inspection.

4. Safe Patch Remediation

server/src/services/llmService.ts

  • Dual-mode AI: Google Gemini 1.5 Flash + Deterministic Heuristic Fallback.
  • Generates copyable coding agent prompts.
  • Human-in-the-loop approval gate prevents silent repository writes.
Core Engineering Practice to Reuse:

Separation of Deterministic Facts from LLM Hypotheses. By allowing static AST analysis to discover verified code relationships and reserving the LLM for explanations and patch suggestions, CodePulse achieves zero hallucinations in dependency graphing while maximizing reasoning quality.
